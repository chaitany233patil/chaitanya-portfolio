# Chaitanya Portfolio
A personal portfolio website built with React and Next.js, utilizing TypeScript for a robust and maintainable codebase.

## Project Overview
This repository contains the source code for a personal portfolio website, featuring a collection of components and pages built with React and Next.js. The project leverages TypeScript for type safety and utilizes popular libraries like Framer Motion and Tailwind CSS for animations and styling.

## Available Scripts
The following scripts are available in the `package.json` file:
* `dev`: Starts the development server
* `build`: Builds the application for production
* `start`: Starts the production server
* `lint`: Runs ESLint to check for code errors and warnings
* `postbuild`: Runs after the build process to generate additional files

## Technologies Used
* **TypeScript**: For type safety and maintainability
* **React**: For building reusable UI components
* **Next.js**: For server-side rendering and routing
* **Framer Motion**: For animations and motion effects
* **Tailwind CSS**: For styling and layout management

## File Structure
The project is organized into the following directories:
* `app`: Contains the main application code
* `components`: Holds reusable UI components
* `public`: Serves static assets and files
* `package.json`: Defines dependencies and scripts for the project
